UNQUALIFIED - test build (Windows)

1. Keep every file in this folder together and run UNQUALIFIED.exe.
   If Windows says "Windows protected your PC": More info, then Run anyway.
2. You start in the apartment. Use the computer to apply for a job:
   every lie on your CV pays more and makes the shift harder.
3. After your first paid shift, a box of parts turns up at the front door.
   The workshop is through the opening beside the computer desk: build a
   gadget on the bench, pack it at the charging rack, and press G at work
   to use it (the key can be changed in the menu). Getting caught with it
   costs you, like any other lie.
4. Esc opens the menu (settings, restart, quit).

Found a bug or a crash?
   Esc > "Report a problem" opens the log folder.
   Send Player.log (or Player-prev.log if the game crashed) to the developer,
   with a line about what you were doing.
